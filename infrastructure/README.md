# infrastructure/

Local development environment provisioning and orchestration.

## Layout
- `docker/`   — service-specific Dockerfiles and helper images (api, web, worker, deps).
- `nginx/`    — reverse-proxy configuration for local/staging environments.
- `scripts/`  — operational helper scripts (db init, seed, backup, dev bootstrap).
