# apps/web

Next.js + TypeScript + Tailwind + shadcn/ui frontend shell for the Family Media System.

## Responsibilities
- Authentication UI flows integrating JWT tokens.
- Photo gallery, music player, timeline navigation, filtering.
- Versioned REST API consumption with secure session handling.
- Dark mode, responsive UI, sidebar navigation, timeline-first UX.
